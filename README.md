# 浏览器工作台

一个浏览器新标签页插件：安装后新建标签页即变为个人工作台，包含搜索、快捷跳转、记账、便签、待办、体重管理、疼痛日记、食材统计、采购清单、计划菜谱等功能。

数据全部存储在浏览器本地，不需要服务器，安装即用。
